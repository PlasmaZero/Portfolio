THE OVERVIEW

Data visualization

An exploratory dashboard connecting a Python analysis pipeline with coordinated, interactive D3.js views.

What it explores

This course project explores 500 student records through dimensionality reduction and clustering. A Python pipeline prepares the data, and coordinated D3.js views let a viewer inspect components and cluster assignments.

The problem to solve

A table of many variables can obscure the structure in a dataset. The goal was to make that structure explorable while keeping the preprocessing and analysis steps explicit.

Inside the build

01

Prepare the records

Processed 500 student records with imputation and standardization before analysis.

02

Reduce and group dimensions

Applied principal component analysis and k-means to explore lower-dimensional patterns and groupings.

03

Connect the views

Built coordinated D3.js views with component selection and clustering controls.
