THE OVERVIEW

AI & automation

A Python agent connecting portfolio review and proposed trades through an authenticated MCP interface.

What it explores

The project connects a Claude Agent SDK loop to the Robinhood MCP interface. Strategy instructions guide analysis, while configuration controls which tools the agent can access.

The problem to solve

An agent that can read a portfolio and propose actions needs a deliberate separation between analysis and execution. Prompt instructions alone are not an enforcement boundary.

Inside the build

01

Connect authenticated tools

Used an OAuth-authenticated MCP connection to review holdings, buying power, and proposed trades.

02

Keep execution opt-in

Configured dry-run defaults and a tool allowlist that excludes order-placement tools unless live trading is explicitly enabled.

03

Support repeatable workflows

Added configurable strategy instructions, symbol restrictions, prompt-level spending limits, and one-shot or scheduled execution.

HOW THE PIECES CONNECT
  1. 01Strategy instructions→
  2. 02Agent + tool allowlist→
  3. 03OAuth-authenticated MCP

Prompt-level limits are instructions, not guaranteed financial controls. The project defaults to dry-run analysis.
