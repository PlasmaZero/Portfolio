THE OVERVIEW

Full-stack

A full-stack workspace for sports odds comparison, expected-value analysis, and manual bet tracking.

What it explores

EVHunter brings odds comparison, pricing calculations, and manual tracking into one application. A Next.js interface connects to a Python API, with PostgreSQL for records and Redis for collection coordination.

The problem to solve

Odds only become comparable when outcomes, fees, and limits line up. The application also needs to keep monetary records consistent when requests arrive at the same time.

Inside the build

01

Compare matching outcomes

Implemented fee-adjusted arbitrage and fractional-Kelly calculations with explicit cent rounding, liquidity limits, and stake allocation.

02

Separate demo and live records

Kept demonstration data isolated from live records so a test session does not become part of the real tracking history.

03

Protect session and balance state

Added signed sessions, CSRF protection, login throttling, and transaction-backed settlement with integration tests for concurrent requests and duplicate balance updates.
