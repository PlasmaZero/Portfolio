THE OVERVIEW

Game development

A code-built research facility, escalating night cycles, and a machine that moves only when unobserved.

What it explores

Night Shift is a Roblox survival horror project set in the HELIOS-7 research facility. The environment, task stations, lighting, and SENTINEL rig are built programmatically rather than assembled by hand.

The problem to solve

The game needs a coherent loop: maintain the facility, manage limited resources, watch the hunter, and reach the exit. Multiplayer mechanics also need a clear boundary between player input and authoritative game state.

Inside the build

01

Build the world in code

A data-driven map builder creates rooms, task terminals, hiding pods, patrol waypoints, lighting, and player suits.

02

Give the hunter readable behavior

The SENTINEL freezes when observed, investigates noise, and signals its state through its visor, core, and lighting.

03

Coordinate the night cycle

A phase state machine connects preparation, tasks, escape, and failure. Server-timed skill checks, server-authoritative stamina, and persistent statistics support the loop.
