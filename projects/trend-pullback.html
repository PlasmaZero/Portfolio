THE OVERVIEW

Technical indicators

A configurable indicator combining moving-average trends, RSI crossovers, and pullback conditions.

What it explores

The indicator expresses trading rules through long, short, and flat states. Multiple entry modes let the same charting tool combine trend-following and pullback conditions.

The problem to solve

Entry and exit conditions can overlap. The project makes state transitions explicit and prioritizes exits so alerts follow a consistent sequence.

Inside the build

01

Configure the entry logic

Created three entry modes combining moving-average trends, RSI crossovers, and pullback conditions.

02

Track position state

Represented long, short, and flat states with explicit exit priority.

03

Surface state changes

Added entry and exit alerts for use within TradingView.
